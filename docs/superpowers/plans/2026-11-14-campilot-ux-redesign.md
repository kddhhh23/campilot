# Campilot 첫 사용자 UX 개편

요청: 디자인을 개선하고 처음 사용하는 사람이 전체 흐름과 다음 행동을 이해하도록 직접 적용한다.
사용 스킬: frontend-design, ui-ux-pro-max, writing-plans. 기존 자율 구현 승인에 따라 추가 승인 대기 없이 진행한다.

## 디자인 결정
- 색: 안개 #EEF3F1, 종이 #FFFFFF, 숲 #245C4D, 잉크 #19352F, 보조 #526960, 주의 #9A4E13.
- 글자: Android 기본 한글 sans-serif. 제목 36sp, 본문 20sp, 보조 16sp, 버튼 20sp. 버튼 최소 60dp.
- 낮 화면 기본, 밤 화면 제공. 넓은 차량 화면에서는 캠핑장 후보 3개를 나란히 비교하고 큰 글꼴/좁은 화면에서는 세로 배치.
- 캠핑장별 벡터 풍경(숲/호수/산)으로 기억할 수 있게 한다. 장식은 이 그림에 집중한다.
- 현재 단계와 다음 행동을 분리. 화면 하단에 주 행동을 고정하고 계산식/SDK/시연 도구는 접힌 상세에 둔다.
- 목업·실제 데이터 구분은 유지하되 사용자 언어로 표현: 시연 모드 / 차량 연결.
- 일반 설정은 체류 시간 중심. 전비·용량·예비 잔량은 고급 설정.
- 원본 검색 결과의 웹 랜딩 페이지/영문 폰트 권고는 차량 한글 앱에 부적합해 적용하지 않음. 계층·대비·터치·점진적 정보 공개 원칙만 적용.
- adaptive 스킬은 Nav3/실험 API 중심이므로 이번 화면 개편에 전체 워크플로를 적용하지 않음. 기존 상태 구조와 안정된 Compose 레이아웃을 유지.

## 화면 구조
상단: 브랜드 / 차량 또는 시연 상태 / 설정
본문: 단계 → 짧은 제목 → 핵심 판단 또는 장소 선택 → 상세(접기)
하단: 선택한 장소/안내 + 주 행동 한 개
추천에서 설정/시연으로 이동 가능. 초기화는 확인 대화상자로 보호.

## 작업
1. 공통 테마/풍경/버튼/상세 컴포넌트. MainActivity 화면 껍데기와 설정 단순화.
2. 추천·전력·이동·충전·차박·완료 화면 재구성. SDK/계산/안전 로직은 유지.
3. 기존 UI 여정 테스트를 새 문구와 구조에 맞게 갱신. 첫 화면, 숨겨진 고급 설정, 고정 행동, 400dp/큰 글꼴 검증.
4. 전체 빌드/단위/기기/Lint, 에뮬레이터 낮/밤 화면 확인, APK 및 변경 보고서 저장.

## 검증 초점
- 시연과 실제 차량을 혼동하지 않음.
- 주 행동이 스크롤 아래로 사라지지 않음.
- 실패/부족한 배터리에서는 진행 제한과 이유가 보임.
- 큰 글꼴에서 버튼과 경고 접근 가능.
- 재생성 시 장소 선택 유지, 여정 초기화에는 확인 필요.
