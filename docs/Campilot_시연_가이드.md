# Campilot 프로토타입 시연 가이드

## 실행

- APK: [Campilot-prototype-debug.apk](../artifacts/Campilot-prototype-debug.apk)
- 검증 환경: Pleos Connect v2.1.0, Android 14 x86_64 emulator.
- Android Studio에서 app을 실행하거나 adb install -r로 APK를 설치한다.
- package: com.example.campilot / Activity: .MainActivity
- 별도 로그인·API 키·서버·위치 권한이 필요하지 않다.
- 실제 차량 SDK와 연결되지 않는다. 전력 예측·공조 소비 변화는 가상 시연이다.

## 권장 90초 진행

1. 계획에서 기본값(60kWh, 잔량60%, 전비5, 체류8h, 다음 이동25km, 예비10%, 난방22°C, 범위18~26°C)을 확인한다.
2. 캠핑장 비교로 이동한다. 솔숲·호수·별빛의 거리와 충전 필요 여부를 비교한다.
3. 솔숲을 선택하고 전력 예산을 확인한다. 이동4kWh, 체류9.6kWh, 다음 이동5kWh, 예비6kWh를 설명한다.
4. 도착 후 차박 시연을 시작한다. 이동 소비가 차감된 잔량53.3%로 시작한다.
5. 자동 공조를 켠 뒤 과소비를 누른다. 평균 소비가3.0kW가 되고 충전 부족 예상에 따라 난방 온도가0.5도씩 낮아진다.
6. 변경 확인 중 상태와 적용 완료 문구를 확인한다. 시간2초가 가상1분이므로 수 초 후 추가 조절이 가능하다.
7. 자동 제어 중지를 눌러 더 이상 공조를 변경하지 않는 것을 보여준다.
8. 정상으로 복구 후 명령 실패 또는 연결 해제 시나리오를 재현한다. 오류를 해결한 뒤 자동 공조는 직접 다시 켠다.

## 조작 규칙

- 수동 온도 조절은 자동 공조를 중지한다.
- 주행 전환·권한 거부·오래된 값은 가상 상태다. 실제 플랫폼 신호를 받는 것이 아니다.
- 다른 캠핑장을 선택하면 기존 체류를 초기화하고 새로운 이동 예산부터 시작한다.
- 화면을 벗어나 앱이 비활성화되면 자동 공조가 중지된다. 복귀 후 직접 켠다.
- 앱 종료·재시작 시 계획 입력만 저장되며 진행 중 차박 세션은 재개하지 않는다.
- 시연 초기화는 저장된 계획을 유지하고 관측값·공조·시간을 초기 상태로 돌린다.
- 화면 하단 탭은 스크롤 위치와 관계없이 이동할 수 있다. 입력 버튼이 아래에 있으면 화면을 스크롤한다.
- 모든 캠핑장명·숙박 허용 여부·시설·거리·위치가 가상이다.
